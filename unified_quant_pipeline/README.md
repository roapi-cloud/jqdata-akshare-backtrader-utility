# 统一量化策略流水线框架

## 架构设计

```
统一量化策略流水线架构
======================

[数据层] --> [因子层] --> [择时层] --> [模型层] --> [策略层] --> [回测层] --> [风控层]
    |            |            |            |            |            |            |
 AKShare      技术因子    大盘择时     ML模型      选股策略    Backtrader   仓位控制
 JQData       基本面因子  个股择时     规则模型    ETF轮动    绩效分析    止损机制
 缓存         情绪因子    信号融合     集成模型    事件驱动    风险指标    压力测试
```

## 模块说明

| 模块 | 路径 | 职责 |
|------|------|------|
| 核心框架 | `core/` | 抽象基类、配置系统、注册中心、流水线编排 |
| 数据层 | `data/` | 多数据源适配、缓存管理、数据质量验证 |
| 因子层 | `factors/` | 技术因子、基本面因子、情绪因子、ML衍生因子 |
| 择时层 | `timing/` | 大盘择时、个股择时、信号融合、仓位管理 |
| 模型层 | `models/` | ML模型、规则模型、集成学习 |
| 策略层 | `strategy/` | 选股策略、ETF轮动、事件驱动、组合管理 |
| 回测层 | `backtest/` | Backtrader引擎适配、绩效分析、报告生成 |
| 风控层 | `risk/` | 仓位控制、止损机制、风险敞口、压力测试 |
| 工具层 | `utils/` | 技术指标、日志、可视化、辅助函数 |
| 配置 | `configs/` | YAML配置文件 |
| 示例 | `examples/` | 可直接运行的示例 |

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 运行选股策略示例
python examples/run_stock_selection.py

# 运行ETF轮动示例
python examples/run_etf_rotation.py

# 运行ML流水线示例
python examples/run_ml_pipeline.py
```

## 设计原则

1. **组件化**: 每个模块独立可替换，通过注册中心动态加载
2. **配置驱动**: 所有参数通过YAML配置，无需修改代码
3. **防泄露**: 严格按时间截面处理数据，防止未来函数
4. **可扩展**: 新策略只需实现对应接口并注册
5. **可复现**: 固定随机种子，记录所有配置和版本
