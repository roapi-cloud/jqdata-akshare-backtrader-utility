# Diagnostic Reports Knowledge Base

Daily diagnostic reports are stored in this directory, organized by date.

## Directory Structure

```
diagnostic_reports/
├── YYYY-MM/
│   ├── YYYY-MM-DD_regime_report.md
│   ├── YYYY-MM-DD_regime_report.json
│   └── ...
```

## File Format

- **Markdown (.md)**: Human-readable diagnostic report
- **JSON (.json)**: Structured data for programmatic consumption

## Usage

Reports are auto-generated by the MarketDiagnosticEngine. Use the KnowledgeBaseManager to query and retrieve historical reports.

## Metadata

Each report includes:
- Date of analysis
- Composite regime classification
- All state classifications and scores
- Key evidence and counter-evidence
- Strategy mapping recommendations
- Confidence level
