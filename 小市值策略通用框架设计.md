# 小市值策略通用框架设计

## 一、策略类型概述

### 核心逻辑
小市值策略的核心逻辑是**市值因子溢价**——A股市场中小市值股票长期存在超额收益。所有策略的共同流程为：
1. 构建初始股票池（全A或特定指数成分股）
2. 过滤不合格股票（ST/停牌/涨跌停/次新/科创板/北交所）
3. 通过因子筛选/评分/排序选出优质小市值股票
4. 按市值升序取最小市值的N只股票
5. 等权配置持仓，定期调仓

### 适用场景
- 震荡上行市、小盘股轮动行情
- 流动性充裕期、市场情绪回暖期
- 财报发布后（财务因子数据更新）

### 风险特征
- **高收益高波动**：年化60%-400%，最大回撤20%-40%
- **流动性风险**：极小市值股票在极端行情下可能无法及时卖出
- **因子失效风险**：小市值因子存在周期性失效（如2017年白马行情、2024年国九条）
- **集中度风险**：持股3-10只时单只股票影响巨大

## 二、子策略变体分类

### 变体1：纯市值排序型（最基础）
**代表策略**：`80 经典小市值深度研究模型`、`15 小市值策略之再优化`、`47 高收益低回撤的小市值策略`
- **差异点**：仅按流通市值/总市值升序排序，无额外因子
- **选股公式**：`order_by(valuation.circulating_market_cap.asc()).limit(N)`
- **股票池**：中小板指数(399101)或沪深全A

### 变体2：多因子打分型
**代表策略**：`02 7年40倍绩优低价超跌缩量小盘`、`01 AI因子小市值选股`
- **差异点**：多因子加权打分后取Top%，再按市值排序
- **因子组合**：市值+价格+成交量+涨幅+财务指标
- **评分方法**：线性加权 `score = w1*log(min0/MC) + w2*log(min1/CMC) + ...`

### 变体3：AI/机器学习因子型
**代表策略**：`01 wywy1995大侠的AI因子选股`、`19 机器学习线性回归小市值`、`64 基于XGBoost滚动选股`
- **差异点**：使用AI/ML训练因子权重，5组因子组合并行选股
- **因子组示例**：
  - 组1: ARBR + SGAI + net_profit_to_total_operate_revenue_ttm + retained_profit_per_share
  - 组2: Price1Y + total_profit_to_cost_ratio + VOL120
  - 组3: price_no_fq + total_profit_to_cost_ratio + inventory_turnover_rate
- **模型**：线性回归、XGBoost、SVR、随机森林

### 变体4：成长因子型
**代表策略**：`01 小市值成长股策略更新`、`63 5年12倍-小市值`、`29 高增长业绩股池小市值成长型`
- **差异点**：在三路选股路径中嵌入成长因子
- **路径1(SG)**：营业收入增长率前10% → 市值最小
- **路径2(MS)**：复合增长率加权评分 → 市值最小
  - 权重：营收增长率(0.1) + 利润总额增长率(0.35) + 净利润增长率(0.15) + 5年盈利增长率(0.4)
- **路径3(PEG)**：PEG升序前20% → 换手率波动率前50% → 市值最小

### 变体5：股息率/价值型
**代表策略**：`35 菜场大妈股息率小市值`、`15 高股息低杠杆小市值轮动`
- **差异点**：先按股息率筛选，再按市值排序
- **股息率计算**：`dividend_ratio = bonus_amount_rmb / market_cap`
- **附加过滤**：低杠杆(MLEV)、低PB、PEG<0

### 变体6：国九条合规型
**代表策略**：`06 国九小市值策略`、`43 小市值再优化`、`76 小市值止损策略`
- **差异点**：加入国九条财务合规筛选
- **筛选条件**：
  - 净利润 > 0
  - 营业收入 > 1亿
  - 市值范围：5-100亿
- **特色**：动态持股数量(3-6只)、双重止损、空仓月份(1月/4月)

### 变体7：择时增强型
**代表策略**：`06 PEG+成长+小市值+RSRS择时`、`83 大小外择时小市值`、`47 高收益低回撤`
- **差异点**：加入市场择时信号控制仓位
- **择时方法**：
  - MA均线：`close > MA10` 牛市满仓，`close < MA10` 熊市30%仓位
  - RSRS：斜率标准分 `zscore * r2`，阈值±0.7
  - 大小盘轮动：比较大市值vs小市值N日涨幅均值
  - RSI：多周期RSI区间判断

### 变体8：微盘股型
**代表策略**：`53 TSmall-100 微盘三正`、`53 微盘股400每日轮动`、`73 微盘400每日再平衡`
- **差异点**：聚焦微盘股指数(399317)，持仓100只，每日调仓
- **筛选条件**：PB>0、inc_return>0、ocf_to_revenue>0
- **特色**：高频再平衡、大样本分散风险

### 变体9：涨停板管理型（通用增强）
**几乎所有策略都包含**
- **差异点**：昨日涨停股开板即卖出，未开板则继续持有
- **实现**：14:00检查持仓中昨日涨停股，比较last_price与high_limit

### 变体10：行业轮动型
**代表策略**：`35 小市值市场轮动版`、`83 大小外择时小市值`
- **差异点**：先选强势行业，再从行业成分股中选小市值
- **行业筛选**：计算各行业成分股C>MA20的比例，取Top N行业

#### 模块1: 股票池构建器 (StockPoolBuilder)

```python
class StockPoolBuilder:
    """构建初始股票池，支持多种股票池来源"""
    
    def __init__(self, config):
        self.config = config
        
    def build(self, context) -> List[str]:
        """构建初始股票池"""
        if self.config.pool_source == "all_a":
            # 全A股：get_all_securities('stock', date).index.tolist()
            initial_list = get_all_securities('stock', context.previous_date).index.tolist()
        elif self.config.pool_source == "index":
            # 指数成分股：get_index_stocks(index_code)
            initial_list = get_index_stocks(self.config.pool_index)
        elif self.config.pool_source == "hot_industry":
            # 热门行业成分股
            initial_list = self._get_hot_industry_stocks(context)
        
        # 基础过滤
        initial_list = self._filter_basic(initial_list, context)
        return initial_list
    
    def _filter_basic(self, stock_list, context) -> List[str]:
        """基础过滤：ST/退市/科创/北交/次新"""
        current_data = get_current_data()
        yesterday = context.previous_date
        filtered = []
        for stock in stock_list:
            # ST过滤
            if current_data[stock].is_st:
                continue
            if 'ST' in current_data[stock].name or '*' in current_data[stock].name:
                continue
            if '退' in current_data[stock].name:
                continue
            # 板块过滤
            if self.config.exclude_kcb and stock.startswith('688'):
                continue
            if self.config.exclude_bse and (stock.startswith('4') or stock.startswith('8')):
                continue
            if self.config.exclude_cyb and stock.startswith('30'):
                continue
            # 次新股过滤
            start_date = get_security_info(stock).start_date
            if yesterday - start_date < timedelta(days=self.config.new_stock_days):
                continue
            filtered.append(stock)
        return filtered
```

#### 模块3: 评分排序器 (Scorer)

```python
class Scorer:
    """多因子评分排序"""
    
    def score_linear_weighted(self, factor_df: pd.DataFrame, weights: Dict[str, float]) -> pd.DataFrame:
        """线性加权评分"""
        factor_df = factor_df.dropna()
        factor_df['total_score'] = 0
        for factor, weight in weights.items():
            factor_df['total_score'] += weight * factor_df[factor]
        return factor_df.sort_values('total_score', ascending=False)
    
    def score_rank_weighted(self, factor_df: pd.DataFrame, weights: Dict[str, float]) -> pd.DataFrame:
        """排名加权评分"""
        factor_df = factor_df.dropna()
        factor_df['total_score'] = 0
        for factor, weight in weights.items():
            factor_df[f'rank_{factor}'] = factor_df[factor].rank()
            factor_df['total_score'] += weight * factor_df[f'rank_{factor}']
        return factor_df.sort_values('total_score', ascending=False)
    
    def filter_by_percentile(self, scored_df: pd.DataFrame, top_pct: float) -> List[str]:
        """取前N%"""
        n = int(top_pct * len(scored_df))
        return list(scored_df.index[:n])
```

**实际代码来源**：
- 线性加权: `01 AI因子选股:149-152` → `df['total_score'] += coef_list[i]*df[factor_list[i]]`
- 排名加权: `02 7年40倍:123` → `score = w1*log(min0/MC) + w2*log(min1/CMC) + ...`
- 百分位筛选: `03 小市值适配因子:44` → `filter_list = list(df.code)[int(p1*len(stock_list)):int(p2*len(stock_list))]`

```python
class StockSelector:
    """最终选股"""
    
    def select_by_market_cap(self, candidate_list: List[str], context, 
                              num_stocks: int, ascending: bool = True) -> List[str]:
        """按市值排序选股"""
        yesterday = context.previous_date
        q = query(
            valuation.code,
            valuation.circulating_market_cap,
            indicator.eps
        ).filter(
            valuation.code.in_(candidate_list)
        ).order_by(
            valuation.circulating_market_cap.asc() if ascending else valuation.circulating_market_cap.desc()
        )
        df = get_fundamentals(q, date=yesterday)
        # EPS过滤
        if self.config.eps_min is not None:
            df = df[df['eps'] > self.config.eps_min]
        return list(df.code)[:num_stocks]
    
    def select_multi_path_union(self, paths: List[List[str]], context, 
                                 num_stocks: int, per_path: int) -> List[str]:
        """多路径选股并集（成长股策略模式）"""
        union_list = list(set().union(*[p[:per_path] for p in paths]))
        return self.select_by_market_cap(union_list, context, num_stocks)
```

```python
class RiskFilter:
    """风控过滤"""
    
    def filter_paused(self, stock_list: List[str]) -> List[str]:
        """过滤停牌"""
        current_data = get_current_data()
        return [s for s in stock_list if not current_data[s].paused]
    
    def filter_limitup(self, stock_list: List[str], context, 
                        include_held: bool = True) -> List[str]:
        """过滤涨停（持仓股除外）"""
        last_prices = history(1, unit='1m', field='close', security_list=stock_list)
        current_data = get_current_data()
        if include_held:
            return [s for s in stock_list 
                    if s in context.portfolio.positions.keys() 
                    or last_prices[s][-1] < current_data[s].high_limit]
        return [s for s in stock_list if last_prices[s][-1] < current_data[s].high_limit]
    
    def filter_limitdown(self, stock_list: List[str], context,
                          include_held: bool = True) -> List[str]:
        """过滤跌停（持仓股除外）"""
        last_prices = history(1, unit='1m', field='close', security_list=stock_list)
        current_data = get_current_data()
        if include_held:
            return [s for s in stock_list 
                    if s in context.portfolio.positions.keys() 
                    or last_prices[s][-1] > current_data[s].low_limit]
        return [s for s in stock_list if last_prices[s][-1] > current_data[s].low_limit]
    
    def filter_high_price(self, stock_list: List[str], context,
                           max_price: float = 50) -> List[str]:
        """过滤高价股"""
        last_prices = history(1, unit='1m', field='close', security_list=stock_list)
        return [s for s in stock_list 
                if s in context.portfolio.positions.keys() 
                or last_prices[s][-1] < max_price]
    
    def filter_not_buy_again(self, stock_list: List[str], 
                              blacklist: List[str]) -> List[str]:
        """过滤近期不再买入的股票"""
        return [s for s in stock_list if s not in blacklist]
    
    def filter_guojiu(self, stock_list: List[str], context) -> List[str]:
        """国九条合规筛选"""
        yesterday = context.previous_date
        q = query(
            valuation.code,
            income.np_parent_company_owners,
            income.net_profit,
            income.operating_revenue
        ).filter(
            valuation.code.in_(stock_list),
            income.np_parent_company_owners > 0,
            income.net_profit > 0,
            income.operating_revenue > 1e8
        )
        df = get_fundamentals(q, date=yesterday)
        return list(df.code)
    
    def filter_audit_opinion(self, stock_list: List[str], context) -> List[str]:
        """审计意见筛选"""
        filtered = []
        last_year = (context.previous_date.replace(
            year=context.previous_date.year - 3, month=1, day=1)).strftime('%Y-%m-%d')
        for code in stock_list:
            q = query(finance.STK_AUDIT_OPINION).filter(
                finance.STK_AUDIT_OPINION.code == code,
                finance.STK_AUDIT_OPINION.pub_date >= last_year
            )
            df = finance.run_query(q)
            df['report_type'] = df['report_type'].astype(str)
            contains_nums = df['report_type'].str.contains(r'2|3|4|5')
            if not contains_nums.any():
                filtered.append(code)
        return filtered
```

#### 模块6: 择时控制器 (MarketTimer)

```python
class MarketTimer:
    """市场择时"""
    
    def get_ma_signal(self, context, index_code: str = '000300.XSHG',
                       ma_period: int = 10, threshold: float = 0.003) -> float:
        """MA均线择时"""
        today = context.previous_date
        start = today - timedelta(days=ma_period * 2)
        df = get_price(index_code, start_date=start, end_date=today, frequency='daily')
        df['ma'] = df['close'].rolling(window=ma_period).mean()
        last = df.iloc[-1]
        diff = last['close'] - last['ma']
        
        if diff >= 500:
            return 1.0  # 牛市满仓
        elif diff >= 200:
            return 1.0
        elif diff >= -200:
            return 1.0
        elif diff >= -500:
            return 0.5  # 半仓
        else:
            return 0.3  # 熊市30%仓位
    
    def get_rsrs_signal(self, context, index_code: str = '000300.XSHG',
                         N: int = 18, M: int = 600, threshold: float = 0.7) -> str:
        """RSRS择时"""
        data = attribute_history(index_code, N + M, '1d', ['high', 'low'])
        slopes = []
        for i in range(M):
            slope, intercept = np.polyfit(data.low[i:i+N], data.high[i:i+N], 1)
            slopes.append(slope)
        
        mean = np.mean(slopes[-M:])
        std = np.std(slopes[-M:])
        zscore = (slopes[-1] - mean) / std
        
        _, _, r2 = get_ols(data.low[-N:], data.high[-N:])
        rsrs_score = zscore * r2
        
        if rsrs_score > threshold:
            return "BUY"
        elif rsrs_score < -threshold:
            return "SELL"
        return "KEEP"
    
    def get_big_small_rotation_signal(self, context, N: int = 10) -> str:
        """大小盘轮动择时"""
        dt_last = context.previous_date
        # 大市值Top20
        B_stocks = get_index_stocks('000300.XSHG', dt_last)
        q = query(valuation.code).filter(valuation.code.in_(B_stocks)).order_by(
            valuation.circulating_market_cap.desc()).limit(20)
        Blst = list(get_fundamentals(q, date=dt_last).code)
        
        # 小市值Top20
        S_stocks = get_index_stocks('399101.XSHE', dt_last)
        q = query(valuation.code).filter(valuation.code.in_(S_stocks)).order_by(
            valuation.circulating_market_cap.asc()).limit(20)
        Slst = list(get_fundamentals(q, date=dt_last).code)
        
        # 计算N日涨幅均值
        B_ratio = get_price(Blst, end_date=dt_last, frequency='1d', fields=['close'], count=N)
        B_mean = (B_ratio.iloc[-1] / B_ratio.iloc[0] - 1).mean() * 100
        
        S_ratio = get_price(Slst, end_date=dt_last, frequency='1d', fields=['close'], count=N)
        S_mean = (S_ratio.iloc[-1] / S_ratio.iloc[0] - 1).mean() * 100
        
        if B_mean > S_mean and B_mean > 0:
            return 'big' if B_mean <= 5 else 'small'  # 大市值到头了切小
        elif S_mean > 0:
            return 'small'
        return 'etf'  # 都不行就买ETF
    
    def get_rsi_signal(self, context, index_code: str = '000300.XSHG',
                        period: int = 60, rsi_min: float = 47, rsi_max: float = 99) -> bool:
        """RSI择时"""
        hst = attribute_history(index_code, period + 1, '1d', ['close'])
        close = [float(x) for x in hst['close']]
        rsi = talib.RSI(np.array(close), timeperiod=period)[-1]
        return rsi_min < rsi < rsi_max
```

```python
class PositionManager:
    """仓位管理"""
    
    def allocate_equal_weight(self, target_list: List[str], context,
                               position_signal: float = 1.0) -> Dict[str, float]:
        """等权分配"""
        available_cash = context.portfolio.cash * position_signal
        num_stocks = len(target_list)
        if num_stocks == 0:
            return {}
        value_per_stock = available_cash / num_stocks
        return {stock: value_per_stock for stock in target_list}
    
    def allocate_with_existing(self, target_list: List[str], context,
                                position_signal: float = 1.0) -> Dict[str, float]:
        """考虑已有持仓的分配"""
        position_count = len(context.portfolio.positions)
        target_num = len(target_list)
        new_buy_count = target_num - position_count
        
        if new_buy_count <= 0:
            return {}
        
        available_cash = context.portfolio.cash * position_signal
        value_per_stock = available_cash / new_buy_count
        return {stock: value_per_stock for stock in target_list 
                if context.portfolio.positions.get(stock, type('obj', (), {'total_amount': 0})()).total_amount == 0}
    
    def allocate_by_market_cap(self, target_list: List[str], context,
                                market_caps: Dict[str, float]) -> Dict[str, float]:
        """市值加权分配（小市值权重更大）"""
        total_value = context.portfolio.total_value
        inverse_caps = {s: 1.0 / market_caps[s] for s in target_list}
        total_inverse = sum(inverse_caps.values())
        return {s: total_value * (inverse_caps[s] / total_inverse) for s in target_list}
```

```python
class TradeExecutor:
    """交易执行"""
    
    def execute_rebalance(self, current_positions: Dict, target_list: List[str],
                           allocation: Dict[str, float], context) -> List[dict]:
        """调仓执行：卖出不在目标列表的，买入目标列表的"""
        orders = []
        
        # 卖出不在目标列表的股票（昨日涨停股除外）
        for stock in current_positions:
            if stock not in target_list and stock not in context.yesterday_HL_list:
                order = self._close_position(context.portfolio.positions[stock])
                orders.append({'action': 'sell', 'stock': stock, 'order': order})
        
        # 买入目标列表中的股票
        for stock, value in allocation.items():
            if value > 0:
                order = self._open_position(stock, value)
                orders.append({'action': 'buy', 'stock': stock, 'order': order, 'value': value})
        
        return orders
    
    def execute_limit_up_check(self, context) -> List[dict]:
        """涨停板检查：昨日涨停股开板即卖出"""
        orders = []
        if not context.yesterday_HL_list:
            return orders
        
        for stock in context.yesterday_HL_list:
            current_data = get_price(stock, end_date=context.current_dt,
                                      frequency='1m', fields=['close', 'high_limit'],
                                      count=1, panel=False, fill_paused=True)
            if current_data.iloc[0]['close'] < current_data.iloc[0]['high_limit']:
                order = self._close_position(context.portfolio.positions[stock])
                orders.append({'action': 'sell_limit_up_open', 'stock': stock, 'order': order})
        
        return orders
    
    def execute_stop_loss(self, context, stop_loss_pct: float = 0.09) -> List[dict]:
        """止损执行"""
        orders = []
        for stock, position in context.portfolio.positions.items():
            price = position.price
            avg_cost = position.avg_cost
            if price < avg_cost * (1 - stop_loss_pct):
                order = order_target_value(stock, 0)
                orders.append({'action': 'stop_loss', 'stock': stock, 'order': order})
        return orders
    
    def execute_take_profit(self, context, take_profit_pct: float = 1.0) -> List[dict]:
        """止盈执行"""
        orders = []
        for stock, position in context.portfolio.positions.items():
            price = position.price
            avg_cost = position.avg_cost
            if price >= avg_cost * (1 + take_profit_pct):
                order = order_target_value(stock, 0)
                orders.append({'action': 'take_profit', 'stock': stock, 'order': order})
        return orders
    
    def _open_position(self, security: str, value: float):
        """开仓"""
        return order_target_value(security, value)
    
    def _close_position(self, position):
        """平仓"""
        return order_target_value(position.security, 0)
```

```python
class SmallCapStrategy:
    """小市值策略主类"""
    
    def __init__(self, config: SmallCapConfig):
        self.config = config
        self.pool_builder = StockPoolBuilder(config)
        self.factor_calc = FactorCalculator()
        self.scorer = Scorer(config)
        self.selector = StockSelector(config)
        self.risk_filter = RiskFilter(config)
        self.market_timer = MarketTimer(config)
        self.position_mgr = PositionManager(config)
        self.trade_executor = TradeExecutor()
        
        # 全局状态
        self.hold_list = []
        self.yesterday_HL_list = []
        self.target_list = []
        self.not_buy_again_list = []
        self.history_hold_list = []
        self.reason_to_sell = ''
        self.trading_signal = True
        
    def initialize(self, context):
        """初始化策略"""
        # 基础设置
        set_benchmark('000905.XSHG')
        set_option('use_real_price', True)
        set_option('avoid_future_data', True)
        set_slippage(FixedSlippage(self.config.slippage))
        set_order_cost(OrderCost(
            open_tax=self.config.open_tax,
            close_tax=self.config.close_tax,
            open_commission=self.config.open_commission,
            close_commission=self.config.close_commission,
            min_commission=self.config.min_commission
        ), type='stock')
        log.set_level('order', 'error')
        
        # 注册定时任务
        run_daily(self.before_trading, '9:05')
        
        if self.config.rebalance_frequency == 'weekly':
            run_weekly(self.rebalance, self.config.rebalance_weekday, self.config.rebalance_time)
        elif self.config.rebalance_frequency == 'monthly':
            run_monthly(self.rebalance, 1, self.config.rebalance_time)
        else:  # daily
            run_daily(self.rebalance, self.config.rebalance_time)
        
        if self.config.manage_limit_up:
            run_daily(self.check_limit_up, self.config.limit_up_check_time)
        
        if self.config.use_stop_loss:
            run_daily(self.stop_loss, '10:00')
        
        run_daily(self.close_account, '14:50')
        run_daily(self.after_trading, '15:10')
    
    def before_trading(self, context):
        """盘前准备"""
        # 更新持仓列表
        self.hold_list = list(context.portfolio.positions.keys())
        
        # 更新昨日涨停列表
        if self.hold_list:
            df = get_price(self.hold_list, end_date=context.previous_date,
                          frequency='daily', fields=['close', 'high_limit'], count=1)
            df = df[df['close'] == df['high_limit']]
            self.yesterday_HL_list = list(df.code)
        else:
            self.yesterday_HL_list = []
        
        # 更新历史持仓（用于不再买入过滤）
        self.history_hold_list.append(self.hold_list)
        if len(self.history_hold_list) >= self.config.blacklist_days:
            self.history_hold_list = self.history_hold_list[-self.config.blacklist_days:]
        temp_set = set()
        for hold_list in self.history_hold_list:
            temp_set.update(hold_list)
        self.not_buy_again_list = list(temp_set)
        
        # 判断是否可交易日（空仓月份检查）
        self.trading_signal = self._check_trading_day(context)
    
    def rebalance(self, context):
        """调仓主流程"""
        if not self.trading_signal:
            # 空仓期买入ETF
            if self.config.use_empty_months:
                self._buy_etf(context, self.config.empty_etf)
            return
        
        # Step 1: 构建股票池
        initial_list = self.pool_builder.build(context)
        
        # Step 2: 计算因子 & Step 3: 评分排序
        candidate_list = self._get_candidates(initial_list, context)
        
        # Step 4: 风控过滤
        candidate_list = self.risk_filter.filter_paused(candidate_list)
        candidate_list = self.risk_filter.filter_limitup(candidate_list, context)
        candidate_list = self.risk_filter.filter_limitdown(candidate_list, context)
        if self.config.max_price:
            candidate_list = self.risk_filter.filter_high_price(candidate_list, context, self.config.max_price)
        if self.config.blacklist_days > 0:
            candidate_list = self.risk_filter.filter_not_buy_again(candidate_list, self.not_buy_again_list)
        
        # Step 5: 择时判断
        position_signal = 1.0
        if self.config.use_market_timing:
            position_signal = self._get_position_signal(context)
        
        # Step 6: 选股
        self.target_list = self.selector.select_by_market_cap(
            candidate_list, context, self.config.stock_num
        )
        
        # Step 7: 仓位分配
        allocation = self.position_mgr.allocate_with_existing(
            self.target_list, context, position_signal
        )
        
        # Step 8: 执行交易
        self.trade_executor.execute_rebalance(
            context.portfolio.positions, self.target_list, allocation, context
        )
    
    def _get_candidates(self, initial_list: List[str], context) -> List[str]:
        """根据策略类型获取候选股票"""
        strategy_type = self.config.strategy_type
        
        if strategy_type == "pure_market_cap":
            # 纯市值排序：直接返回
            return initial_list
        
        elif strategy_type == "multi_factor":
            # 多因子打分
            factor_df = self.factor_calc.calculate(initial_list, context.previous_date, self.config.factors)
            scored_df = self.scorer.score_linear_weighted(factor_df, self.config.factor_weights)
            return self.scorer.filter_by_percentile(scored_df, self.config.top_percent)
        
        elif strategy_type == "ai_factor":
            # AI因子多组并行
            final_list = []
            for factor_list, coef_list in self.config.factor_groups:
                factor_values = get_factor_values(initial_list, factor_list, 
                                                   end_date=context.previous_date, count=1)
                df = pd.DataFrame(index=initial_list)
                for i, f in enumerate(factor_list):
                    df[f] = factor_values[f].iloc[0]
                df = df.dropna()
                df['total_score'] = sum(coef_list[i] * df[f] for i, f in enumerate(factor_list))
                df = df.sort_values('total_score', ascending=False)
                top_list = list(df.index)[:int(self.config.top_percent * len(df))]
                # 再按市值排序
                q = query(valuation.code, valuation.circulating_market_cap, indicator.eps).filter(
                    valuation.code.in_(top_list)
                ).order_by(valuation.circulating_market_cap.asc())
                df_mv = get_fundamentals(q, date=context.previous_date)
                df_mv = df_mv[df_mv['eps'] > 0]
                final_list.extend(list(df_mv.code))
            return list(set(final_list))
        
        elif strategy_type == "growth":
            # 成长因子多路径
            paths = []
            for path in self.config.growth_paths:
                if 'factor' in path:
                    # 单因子路径
                    filtered = self._filter_by_factor(initial_list, path['factor'], 
                                                       path.get('sort', False), path['top_pct'], context)
                    paths.append(filtered)
                elif 'factors' in path:
                    # 多因子加权路径
                    filtered = self._filter_by_multi_factor(initial_list, path, context)
                    paths.append(filtered)
            # 取并集
            return list(set().union(*[p[:5] for p in paths if p]))
        
        elif strategy_type == "dividend":
            # 股息率筛选
            dr_list = self._filter_by_dividend_ratio(initial_list, context, sort=False, p1=0, p2=0.25)
            return dr_list
        
        elif strategy_type == "guojiu":
            # 国九条筛选
            return self.risk_filter.filter_guojiu(initial_list, context)
        
        elif strategy_type == "micro_cap":
            # 微盘股：取微盘指数成分股按市值排序
            micro_stocks = get_index_stocks('399317.XSHE')
            q = query(valuation.code, valuation.market_cap).filter(
                valuation.code.in_(micro_stocks),
                valuation.pb_ratio > 0,
                indicator.inc_return > 0,
                indicator.ocf_to_revenue > 0
            ).order_by(valuation.market_cap.asc()).limit(120)
            df = get_fundamentals(q, date=context.previous_date)
            return list(df.code)
        
        return initial_list
    
    def check_limit_up(self, context):
        """涨停板检查"""
        if not self.yesterday_HL_list:
            return
        
        for stock in self.yesterday_HL_list:
            current_data = get_price(stock, end_date=context.current_dt,
                                      frequency='1m', fields=['close', 'high_limit'],
                                      count=1, panel=False, fill_paused=True)
            if current_data.iloc[0]['close'] < current_data.iloc[0]['high_limit']:
                order_target_value(stock, 0)
                self.reason_to_sell = 'limitup'
    
    def stop_loss(self, context):
        """止损止盈"""
        if not self.config.use_stop_loss:
            return
        
        for stock, position in context.portfolio.positions.items():
            price = position.price
            avg_cost = position.avg_cost
            
            # 止盈
            if price >= avg_cost * (1 + self.config.take_profit_pct):
                order_target_value(stock, 0)
            
            # 个股止损
            if self.config.stop_loss_strategy in [1, 3]:
                if price < avg_cost * (1 - self.config.stop_loss_limit):
                    order_target_value(stock, 0)
                    self.reason_to_sell = 'stoploss'
            
            # 市场止损
            if self.config.stop_loss_strategy in [2, 3]:
                stock_df = get_price(get_index_stocks('399101.XSHE'), 
                                      end_date=context.previous_date,
                                      frequency='daily', fields=['close', 'open'], count=1)
                down_ratio = abs((stock_df['close'] / stock_df['open'] - 1).mean())
                if down_ratio >= self.config.market_stop_loss_pct:
                    for s in context.portfolio.positions:
                        order_target_value(s, 0)
                    self.reason_to_sell = 'stoploss'
    
    def close_account(self, context):
        """空仓期清仓"""
        if not self.trading_signal and self.config.use_empty_months:
            for stock in self.hold_list:
                if stock != self.config.empty_etf:
                    order_target_value(stock, 0)
    
    def after_trading(self, context):
        """盘后处理"""
        # 打印持仓信息
        for position in context.portfolio.positions.values():
            log.info(f"{position.security}: cost={position.avg_cost:.2f}, "
                     f"price={position.price:.2f}, "
                     f"return={100*(position.price/position.avg_cost-1):.2f}%, "
                     f"value={position.value:.2f}")
    
    def _check_trading_day(self, context) -> bool:
        """判断是否为可交易日"""
        if not self.config.use_empty_months:
            return True
        month = context.current_dt.month
        return month not in self.config.empty_months
    
    def _get_position_signal(self, context) -> float:
        """获取仓位信号"""
        method = self.config.timing_method
        if method == "ma":
            return self.market_timer.get_ma_signal(context, ma_period=self.config.ma_period)
        elif method == "rsrs":
            signal = self.market_timer.get_rsrs_signal(context, N=self.config.rsrs_N, M=self.config.rsrs_M)
            return 1.0 if signal in ["BUY", "KEEP"] else 0.0
        elif method == "big_small_rotation":
            signal = self.market_timer.get_big_small_rotation_signal(context)
            return 0.0 if signal == "etf" else 1.0
        return 1.0
    
    def _buy_etf(self, context, etf_code: str):
        """买入ETF"""
        if etf_code not in context.portfolio.positions:
            order_value(etf_code, context.portfolio.available_cash)
    
    def _filter_by_factor(self, stock_list, factor_name, sort_ascending, top_pct, context):
        """单因子筛选"""
        score_list = get_factor_values(stock_list, factor_name, 
                                        end_date=context.previous_date, count=1)[factor_name].iloc[0].tolist()
        df = pd.DataFrame({'code': stock_list, 'score': score_list}).dropna()
        df = df.sort_values('score', ascending=sort_ascending)
        return list(df.code)[:int(top_pct * len(df))]
    
    def _filter_by_dividend_ratio(self, stock_list, context, sort, p1, p2):
        """股息率筛选（同 35 菜场大妈:114-158）"""
        time1 = context.previous_date
        time0 = time1 - timedelta(days=365)
        
        q = query(finance.STK_XR_XD.code, finance.STK_XR_XD.a_registration_date, 
                  finance.STK_XR_XD.bonus_amount_rmb).filter(
            finance.STK_XR_XD.a_registration_date >= time0,
            finance.STK_XR_XD.a_registration_date <= time1,
            finance.STK_XR_XD.code.in_(stock_list)
        )
        df = finance.run_query(q)
        dividend = df.fillna(0).set_index('code').groupby('code').sum()
        
        q = query(valuation.code, valuation.market_cap).filter(valuation.code.in_(dividend.index))
        cap = get_fundamentals(q, date=time1).set_index('code')
        
        DR = pd.concat([dividend, cap], axis=1, sort=False)
        DR['dividend_ratio'] = (DR['bonus_amount_rmb'] / 10000) / DR['market_cap']
        DR = DR.sort_values('dividend_ratio', ascending=sort)
        return list(DR.index)[int(p1*len(DR)):int(p2*len(DR))]
```
